3. STEP 1 — Cloud Database Setup (TiDB Cloud)

TiDB Cloud is a 100% Free Serverless MySQL database hosted on AWS. No credit card required.

  1. Browser-la https://tidbcloud.com poyi "Sign in with Google" kudunga.
  2. "Create Project" click panni, plan-la 👉 Serverless (Free - $0) select pannunga.
  3. Cluster name A1tex nu vachitu Create click pannunga (10 seconds-la cluster ready aagidum).
  4. Screen-la oru Password kaattum (e.g. YourTiDBPassword123). Adha udane Notepad-la copy panni save pannikonga (oru thadava close aana marubadiyum kaattaadhu).
  5. Public IP Firewall Allow Panna (Romba Crucial):
    • Popup-a close pannitu, left menu Settings (⚙️) → Security ponga.
    • IP Access List-la Add Rule click panni:
    • Rule Name: Allow_all_public_connections
    • Start IP: 0.0.0.0 | End IP: 255.255.255.255
    • Submit click pannunga. (Idhanaala Render cloud backend block aagama connect aagum).
  6. Database Create & Test Panna: Local terminal-la intha one-line run panna TiDB-la a1tex_db schema ready aagidum:
    POWERSHELL / TERMINAL 
    cd "d:\Sai Tech\tn\backend\node"; node scripts/init-cloud-db.cjs gateway01.ap-northeast-1.prod.aws.tidbcloud.com 4000 <YOUR_TIDB_USER> <YOUR_TIDB_PASSWORD> a1tex_db

    (Replace gateway01..., <YOUR_TIDB_USER>, and <YOUR_TIDB_PASSWORD> with your TiDB dashboard details).

7. Common Pitfalls & Solutions (Munnadi Vantha Errors & Fixes)

Issue Encountered Root Cause Permanent Solution
Root directory "node" does not exist Root Directory path was typed as node instead of backend/node. Always configure Root Directory as backend/node on Render.
TiDB Cloud Handshake Timeout / SSL Error TiDB Cloud requires TLSv1.2 SSL encryption on port 4000. Code already updated with automatic isCloudDb detection and TLS v1.2 SSL in sequelize.ts.
Unknown database 'a1tex_db' TiDB cluster was fresh and didn't have the database schema created. Run node scripts/init-cloud-db.cjs once locally, or create a1tex_db in TiDB Cloud web console.
CORS blocked / Missing Header Vercel frontends have dynamic domains (*.vercel.app). Configured CORS in app.ts to automatically allow all .vercel.app domains and CORS_ORIGIN=*.
Admin panel 404 NOT_FOUND on page refresh Vercel couldn't resolve direct client-side routes (/login, /orders) in Vite SPA. Added backend/panel/vercel.json with SPA rewrite rule {"source":"/(.*)","destination":"/index.html"}.
